# MMI Definition v0

## Definition

MMI is the ordinary technical access protocol between the stable cognitive core **K** and the separate plastic autobiographical parameter body **Φ(t)**.

## Function

In its current experimental form, MMI serves as an external prompt-and-contract adapter that:

1. states to the model that a separate autobiographical memory exists;
2. declares the presence of nested memory timescales;
3. defines minimal compatibility rules for access;
4. does not decide what the model should remember.

## Non-functions

MMI is not:

- a policy engine;
- a retrieval ranking system;
- a second semantic subject;
- a safety guardrail;
- an executive controller;
- a mechanism for altering the stable core in normal operation.

## Current working assumption

The minimal experimental MMI may be implemented as a short prompt prelude attached to each request.

This is an implementation form, not the final architectural destination.
