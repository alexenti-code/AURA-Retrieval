# Matryoshka Boundary

**Version:** 1.1.0
**Status:** Conceptual scope clarification
**Canonical definition:** [MANIFEST.md](MANIFEST.md)

## What Matryoshka is

Matryoshka Continuity Weights is a self-organizing plastic parameter substrate
of autobiographical memory for a stable language-model core. It preserves and
self-organizes the experience lived by the model within whatever environment is
available to it. A model may self-organize its autobiographical memory within
Matryoshka.

## What Matryoshka is not

- Matryoshka is a memory substrate, not a governance layer.
- Matryoshka does not prescribe goals, permissions, policies, tool access,
  safety guardrails or executive control.
- Matryoshka is not a policy engine and not a system of rights or rules.
- Matryoshka is not an executive layer and does not initiate actions in the
  world.
- Matryoshka is not a mechanism for altering the stable core. It does not
  alter the stable core through normal operation.

## Core stability

The stable cognitive core remains stable through normal operation. Experience
changes only the plastic parameter state that belongs to the same instance,
as defined in [MANIFEST.md](MANIFEST.md).

## Relation to the deployment environment

The deployment environment (sandbox, documents, APIs, access rights and other
externally available capabilities) determines which objects and actions are
actually available to the model. This environment is separate from Matryoshka:
it may limit externally available capabilities, but it is not part of
Matryoshka and does not belong to its definition. Matryoshka preserves and
self-organizes lived experience; it does not define what the environment
permits.

## Terminology note

Earlier exploratory materials in this repository (research-10 .. research-14,
"Plastic Transformer" / "Matryoshka FWH") use preliminary, non-canonical
terminology in which layered cores are discussed together with safety
guardrails. That framing belongs to those early articles and does not define
the canonical concept of Matryoshka Continuity Weights.
